# РГР з дисципліни «Смарт-технології та Інтернет речей» - варіант 9

**Тема:** Енергоефективний розумний будинок та обробка даних.

## Що реалізовано

- генерація семи днів синтетичної телеметрії
- моделювання пропусків та аномальних значень
- очищення числових даних та окрема обробка дискретного показника руху
- збереження пристроїв і показників у реляційній базі SQLite
- формування добової статистики, графіків та оцінки сценарію керування освітленням
- порівняння gzip, zlib та bzip2 із перевіркою зворотного розпакування
- передавання найкомпактнішого набору (bzip2) у Firebase Realtime Database, зворотне отримання та перевірка SHA-256
- контейнеризація запуску засобами Docker та Docker Compose
